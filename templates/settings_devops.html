安全与访问控制（高级可选，默认不展开）
以下功能全部为可选项，默认关闭。未启用时不会改变现有登录与访问流程。建议先在局域网或测试环境验证，再用于生产环境。
功能说明与建议：
  • 只读模式：启用后会阻止新增、编辑、删除等写操作，适合排障/审计窗口。若忘记关闭，可能导致“保存无效”的误解。
  • IP 白名单：仅允许指定 IP 或网段访问。配置错误会造成自己被锁在系统外，建议先加入当前访问 IP 再保存。
  • 管理员 2FA：应用内管理员账号支持动态验证码，详见下方“管理员安全”。
  • Webhook：用于把系统事件推送到外部服务；建议配合密钥校验，仅在可信地址上启用。
  • API 访问令牌：为 API 请求增加额外访问令牌校验。留空即关闭，不影响普通页面操作。
